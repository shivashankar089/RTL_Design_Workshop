# RTL Design Workshop - Day 3

This folder explores constants, counters, optimization, and the difference between RTL and synthesized views.

## Files

- [deff_const2_gtk.png](deff_const2_gtk.png) - GTKWave result for the second constant-driven design example.
- [deff_const2_yosys.png](deff_const2_yosys.png) - Yosys synthesis view for the second constant-driven design.
- [deff_const3_gtk.png](deff_const3_gtk.png) - GTKWave result for the third constant-driven design example.
- [dff_const3_yosys.png](dff_const3_yosys.png) - Yosys synthesis view for the third constant-driven design.
- [dff_const_gtk.png](dff_const_gtk.png) - GTKWave result for a constant-driven D flip-flop example.
- [dff_const_yosys.png](dff_const_yosys.png) - Yosys synthesis view for the constant-driven D flip-flop.
- [good_counter.png](good_counter.png) - Simulation or implementation view of the counter design.
- [opt_check.png](opt_check.png) - First synthesis optimization check.
- [opt_check2.png](opt_check2.png) - Second synthesis optimization check.
- [opt_check3.png](opt_check3.png) - Third synthesis optimization check.

The GTKWave files show simulated signal behavior, while the Yosys files show how constant logic and sequential logic are optimized during synthesis. The counter and optimization checks provide additional implementation references.
