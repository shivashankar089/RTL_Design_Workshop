# RTL Design Workshop - Day 2

This folder covers flip-flops, reset behavior, module hierarchy, and synthesized netlists.

## Files

- [asynchronous.png](asynchronous.png) - Diagram or waveform illustrating asynchronous reset behavior.
- [dff_asy_gtk.png](dff_asy_gtk.png) - GTKWave view of a D flip-flop with asynchronous reset.
- [dff_syncres.png](dff_syncres.png) - Reference for a D flip-flop with synchronous reset.
- [flatten_netlist.png](flatten_netlist.png) - Synthesized netlist after flattening the module hierarchy.
- [multiple_modules.png](multiple_modules.png) - Design containing multiple RTL modules.
- [sub_module1.png](sub_module1.png) - View of a submodule used by the larger design.

The reset examples compare asynchronous and synchronous reset timing. The module and netlist images show how hierarchical RTL is represented before and after synthesis.
