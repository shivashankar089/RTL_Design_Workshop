# RTL Design Workshop - Day 1

This folder introduces multiplexer RTL and the visual checks used to inspect the design.

## Files

- [good_mux_both.png](good_mux_both.png) - Combined view of the good multiplexer implementation and its verification result.
- [good_mux_gtk.png](good_mux_gtk.png) - GTKWave waveform view for the good multiplexer.

The `good_mux` examples demonstrate selecting one input from multiple inputs using a control signal. The screenshots provide a visual reference for simulation and waveform behavior.
